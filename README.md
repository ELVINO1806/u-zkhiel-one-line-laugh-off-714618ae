# One-Line Laugh-Off

An entry for the make.fun One-Line Laugh-Off bounty. The program writes a single funny one-line joke to a file, ready to be judged as a standalone one-liner.

## How it works

Run `python3 main.py` and the entry is written to `/output/entry.txt`. The program uses only the Python standard library and needs no network access. The script also checks that the entry is a single line before writing it, and the entry stays well under the competition's 200-character limit.
